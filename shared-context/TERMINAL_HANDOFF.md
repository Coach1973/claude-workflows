## 六、當前任務（Phase 2）

### 任務名稱：100 個場景（重啟版）

### 任務背景
這兩個月裡，大樹教練為了教 AI 做事，付出了無數個不眠不休、熬夜長出黑眼圈的夜晚。
我們不希望別的老闆也付出這種代價。
把坑填平了，讓他少走彎路。這就是價值所在。

### 任務目標
從兩個月真實對話中，提煉出 100 個「老闆典型需求 × 助理標準回應」場景。
每個場景 = 老闆未來一定會遇到的問題 + 助理的標準回應。
這 100 個場景是「頂級特助系統」交給未來老闆的最有價值交付。

### 兩個方向並行

**方向 A：從兩個月真實對話提煉**
資料來源：memory/ 所有 YYYY-MM-DD.md 檔案
每次教練說「你怎麼又這樣」= 一個場景素材
每次踩坑後總結的結論 = 一個場景素材

**方向 B：從現有素材提取**
資料來源：terminal-notes/distillation/ 所有 FINAL 檔案、feedback_*.md
從「老闆典型需求 × 助理標準回應」範本提取

### 場景格式（新格式）

每個場景必須同時包含：

```
【場景 #XX】
日期：[YYYY-MM-DD]
來源：[方向A：memory/YYYY-MM-DD.md] 或 [方向B：XXX檔案]

教練/老闆說：...
助理說：...
結論：...

商務價值標籤：[這個場景對未來老闆有什麼意義]
助理行為分類：[主動服務/坦誠限制/自動自發/價值觀傳遞/...]
```

### 不納入的內容（暫緩）
- 三機分工相關場景 → 未來獨立專案
- 技術故障內部操作細節 → 未來老闆不需要知道工程師怎麼裝 Chrome

### 優先順序
1. 從 memory/ 讀最早日期的對話（早期互動往往是最典型的踩坑場景）
2. 從 feedback_*.md 提取「老闆教 AI 做事」的典型案例
3. 修補現有缺口（#021-#045，共25個）

### Commit 制度
每完成 5 個場景，立刻 commit + push + 回報 hash。
