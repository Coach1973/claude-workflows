純 shell 指令、改 JSON、curl 測試、服務重啟、git 操作 → 全部交 Hermes CLI，不消耗克勞德 Token。

**Why:** 2026-04-24 三機 bot 跨進程互通任務，直接截圖操作 Telegram + 多輪截圖，短短一小時燒掉 session 95%、週額度 12%。這是不可接受的浪費。

**How to apply:**
1. 收到任務後先判斷類型。純操作類 → 直接說「交給 Hermes，寫任務書」，不問教練確認。
2. 使用 computer-use 前估算截圖輪數。超過 10 輪先回報教練。
3. 克勞德助教只做：分析、設計、寫任務書、決策、驗收。
