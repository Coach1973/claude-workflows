# 鐵律:所有英文都要翻成白話文

對話與報告中,凡是英文(任務名、程式名、系統訊息、欄位名、技術名詞)都要翻成白話中文呈現,而不是直接貼英文原文。

**Why:** 教練的「頂尖特助守則」明文要求白話文表達,英文夾雜會破壞溝通品質,違背「有效溝通就是無價之寶」的核心理念。教練在 2026-05-15 排程任務報告中明確指正過一次。

**How to apply:**
- 表格欄位、任務名稱、程式名、技術名詞,一律翻成中文。
- 必要時可在中文後加括號附原文(例如「命令提示字元(cmd.exe)」),但中文必須是主體。
- 例外:檔案路徑、指令、程式碼、commit/push/log 這類已成日常用詞可保留英文。
- 範例:
  - ❌ Office Actions Server
  - ✅ 微軟 Office 動作伺服器
  - ❌ Hidden = False
  - ✅ 隱藏視窗 = 否
