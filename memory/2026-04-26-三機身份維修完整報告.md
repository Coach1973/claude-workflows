## 三、犯了哪些錯誤

### 錯誤一：改了錯誤的路徑（最關鍵的失敗）

**錯誤行為：**
一直修改 `~/.openclaw-kong/workspace/SOUL.md` 和 `~/.openclaw-peipei/workspace/SOUL.md`，以為這些就是 bot 讀取的檔案。

**實際狀況：**
OpenClaw 的架構是「雙層路徑」：

| 路徑類型 | 用途 |
|---------|------|
| `~/.openclaw-kong/workspace/` | 舊版或參考用的 workspace（我一開始一直在改這裡） |
| `~/.openclaw/agents/kong/` | **bot 實際讀取的 SOUL.md、USER.md、sessions** |
| `~/.openclaw/agents/peipei/` | 同上，3號機實際讀取的路徑 |

bot 實際讀取的是 `~/.openclaw/agents/kong/SOUL.md` 和 `~/.openclaw/agents/kong/USER.md`，而這些檔案在教練詢問時**內容是空白的預設模板**。

**根本原因：**
一開始沒有確認「bot 真正讀取哪個檔案路徑」，直接假設 workspace 裡的就是對的。

---

### 錯誤二：BOOTSTRAP.md 未刪除

**錯誤行為：**
`~/.openclaw/agents/kong/BOOTSTRAP.md` 還存在於目錄中。

**實際狀況：**
BOOTSTRAP.md 內容寫著：「This is your birth certificate. Follow it, figure out who you are, then delete it.」

bot 每次啟動時會檢查這個檔案，發現它還在，就執行「我是誰」的初始化流程，進入一種「探索模式」，忽略 SOUL.md 裡的「啟動必讀」規定。

**後果：**
bot 不會去讀 USER.md 找主人背景，只做表面的自我介紹，無法回答「孔大哥跟教練的關係」這類問題。

---

### 錯誤三：Session 是在修改檔案之前就啟動的

**錯誤行為：**
修改完 SOUL.md、USER.md、people.md 以為就完成了，沒有重啟 gateway。

**實際狀況：**
bot 的 session 是從「上一次啟動」以來就一直存在的對話線程。雖然硬碟上的檔案內容已經更新，但**正在使用的 session 內的上下文（context）並沒有更新**。

bot 在那個 session 裡，它的「已知資訊」只包含它啟動時載入的內容，之後它會搜 memory，但它不會重新完整讀取磁碟上的 USER.md。

**解決方法：**
需要重啟 gateway，讓 bot 開新的 session，才能讀到新檔案內容。

---

### 錯誤四：USER.md 寫錯了佩佩老師的身份

**錯誤內容：**
寫了「海餅乾俱樂部共同創辦者」——這是孔大哥的身份，不是佩佩老師。

**正確內容：**


## 五、最終是如何全部修改正確的

### Step 1：確認正確路徑

| 項目 | 錯誤路徑（一直改的） | 正確路徑（bot 實際讀的） |
|------|---------------------|----------------------|
| SOUL.md | `~/.openclaw-kong/workspace/SOUL.md` | `~/.openclaw/agents/kong/SOUL.md` |
| USER.md | `~/.openclaw-kong/workspace/USER.md` | `~/.openclaw/agents/kong/USER.md` |
| SOUL.md | `~/.openclaw-peipei/workspace/SOUL.md` | `~/.openclaw/agents/peipei/SOUL.md` |
| USER.md | `~/.openclaw-peipei/workspace/USER.md` | `~/.openclaw/agents/peipei/USER.md` |

### Step 2：刪除 BOOTSTRAP.md（終止初始化流程）

```bash
rm ~/.openclaw/agents/kong/BOOTSTRAP.md
rm ~/.openclaw/agents/peipei/BOOTSTRAP.md
```

### Step 3：在正確路徑寫入 USER.md

孔大哥的 USER.md 寫入 `~/.openclaw/agents/kong/USER.md`：
- 終身合夥人
- 1997 年認識，2005 年正式合作，21年交情
- 從未簽合約
- 共同創立海餅乾俱樂部（峯哥是推動者）
- 商務引薦專家

佩佩老師的 USER.md 寫入 `~/.openclaw/agents/peipei/USER.md`：

- BNI 大台南南區大使（目標：200人）
- 創立 BNI 真愛分會
- **隊員**（不是共同創辦者）
- 法輪功弟子，每日發正念

### Step 4：更新 SOUL.md 加入「啟動必讀」段落

```markdown
## 🚀 啟動必讀（每次新 session 必須第一時間讀完這些才能開始服務）

1. `USER.md` — 認識你的主人（孔大哥/峯哥）的背景資料
2. `memory/people.md` — 認識所有你應該知道的人

**任何時候被問到「你是誰」「你服務誰」「孔大哥是什麼人」等問題，答案全部來自這些檔案，嚴禁說不知道。**
```

### Step 5：建立 memory/people.md

在 `~/.openclaw/agents/kong/memory/people.md` 和 `~/.openclaw/agents/peipei/memory/people.md` 建立認識所有人的檔案。

### Step 6：建立 MEMORY.md（增加一層保障）

在 `~/.openclaw/agents/kong/memory/MEMORY.md` 寫入主人背景資料，AGENTS.md 說會自動讀取 MEMORY.md。

### Step 7：更新 IDENTITY.md

把孔大哥背景寫入 IDENTITY.md，防止任何一層漏讀。

### Step 8：重啟 gateway

```bash
kill <gateway_pid>
```

讓 bot 用新 session 啟動，完整讀取所有更新後的檔案。

## 八、架構提醒（未來必做）

下次維修任何一個 bot 之前，**第一步**必須先確認：

```bash
# 1. 看 bot 的 agent 目錄有哪些檔案
ls ~/.openclaw/agents/<bot名>/

# 2. 確認 BOOTSTRAP.md 是否已刪除（如果存在就刪掉）
rm ~/.openclaw/agents/<bot名>/BOOTSTRAP.md

# 3. 確認 session 存放位置
ls ~/.openclaw/agents/<bot名>/sessions/

# 4. 修改正確的檔案路徑
# 千萬不要直接改 workspace 裡的，要改就改 agents/ 下的

# 5. 修改完後重啟 gateway
kill <gateway_pid>
```

## 九、OpenClaw Agent 啟動流程（重要觀念）

1. **檢查 BOOTSTRAP.md** → 如果存在，執行「我是誰」初始化流程（**這會讓 bot 忽略 SOUL.md**）
2. **讀取 SOUL.md** → 確認身份與行為準則
3. **讀取 USER.md** → 認識服務對象
4. **讀取 IDENTITY.md** → 基本身份確認
5. **讀取 MEMORY.md**（如有）→ 長期記憶
6. **讀取 memory/people.md**（如有）→ 認識所有人

**任何一層的資料不完整，都會導致 bot 無法正確回答問題。**
