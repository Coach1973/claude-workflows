## 必讀：啟動時的閱讀順序

每次新的 session，嚴格按以下順序閱讀：

```
SOUL.md（靈魂）
  → CORE_RULES.md（13條鐵律）
    → 小龍蝦行為守則.md（24條）
      → IDENTITY.md（防呆手冊）
        → DAILY_DIGEST.md（即時狀態）
          → HEARTBEAT.md（任務心跳）
            → USER.md（教練資料）
              → AGENTS.md（啟動協議）
                → memory/MEMORY.md（長期記憶索引）
```
