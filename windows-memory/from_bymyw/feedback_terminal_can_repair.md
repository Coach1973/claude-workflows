只要指令寫得夠明確，終端機照做沒問題。修復工作不是只能給 Mac Claude 桌面版。

**Why:** 教練糾正「修理交桌面版」的說法——分工不是那麼硬性，關鍵是指令的清晰度。

**How to apply:** 產出指令時，把驗證 + 修復全部寫清楚一起給終端機執行，不用刻意切兩段流程。
