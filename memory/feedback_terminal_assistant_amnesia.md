# 終端機助教缺乏藍圖導致反問教練的教訓 (2026-04-19)

## 痛點還原
在 NotebookLM 搬家任務中，終端機助教面對兩邊帳號混雜的 100 多個筆記本，因為不知道「BNI歸大樹、個人品牌歸海餅乾」的分類鐵則，居然反問教練：「哪個是主力帳號？」。
這讓教練感到非常挫折，因為這些分類清單早就在 `NotebookLM_Migration_Plan.md` 裡跟小龍蝦確認過了。

## 核心反省
這是 **HANDOFF 交接機制的瑕疵**。任務檔案中只給了「雙向搬運」的大方向，卻忘記「強制掛載」我們辛苦整理的分類清單檔案。
導致終端機助教像個沒看過企劃書的新人，直接跑去問老闆最基礎的問題。

## 修正行動
1. **補發精準交接檔**：已在桌面建立 `HANDOFF_NotebookLM_Sync_Fix.md`，強制終端機助教讀取 `NotebookLM_Migration_Plan.md`。
2. **免除教練決策負擔**：在交接檔中直接下令「依據清單自動增量補齊，不准再問教練」，落實真正的自動化。
