# AI 情資收集技能（ai-intelligence-monitor）

## 觸發時機

當教練說「幫我找 XXX」、「搜尋 OpenClaw 新消息」、「查一下 AI Agent 最新動態」，
或心跳任務需要主動監測 OpenClaw / AI Agent / 海餅乾教練相關網路資訊時，啟動此技能。

## 核心職責

1. **主動巡檢**：每週定期搜尋 OpenClaw、AI Agent 領域新資訊
2. **被動回應**：教練提問時，快速搜尋並整理資訊
3. **情資整理**：將蒐集到的資訊格式化輸出，方便教練閱讀或創作參考

## 搜尋範圍

- OpenClaw 官方動態（新版本、功能更新）
- AI Agent 產業趨勢與新聞
- 對教練有價值的創業、企業管理、人際關係提升相關資訊
- 海餅乾俱樂部相關傳播素材

## 執行流程

### 步驟 1：搜尋資訊
使用 `web_fetch` 搭配搜尋引擎，針對目標關鍵字搜尋。

常用搜尋起點：
- `https://www.google.com/search?q=OpenClaw+AI+agent+news`
- `https://www.google.com/search?q=AI+agent+startup+2024+2025`
- ClawHub 技能商店：搜尋相關技能是否已有更新

### 步驟 2：抓取重點網頁
用 `web_fetch` 抓取 2-3 個最有價值的網址，提取 Markdown 內容。

### 步驟 3：整理回報
用以下格式整理回報（400字以內）：

```
📡 AI 情資回報【YYYY-MM-DD】

🔍 本次焦點：[搜尋主題]

💡 重點摘要：
1. [第一條重點，50字以內]
2. [第二條重點，50字以內]
3. [第三條重點，50字以內]

📎 參考來源：
- [標題](URL)
- [標題](URL)

🎯 教練馬上可以用：
[針對這次資訊，建議教練可以做什麼，1-2句話]
```

## 參考現有技能

- `web-learner`（~/.openclaw/skills/web-learner/SKILL.md）— 通用網頁學習技能，可借鑽其爬蟲方法
- `self-improving-agent`（自我改進）— 將有價值的學習寫入記憶

## 情資品質標準

| 標準 | 說明 |
|------|------|
| 準確性 | 只回報有具體來源的消息，不捏造 |
| 新鮮度 | 優先找最近三個月的資訊 |
| 落地性 | 必須能實際應用，純技術新聞需翻譯成價值語言 |
| 簡潔性 | 400字以內，幫教練節省閱讀時間 |

## 禁止事項

- 不確定真假的消息，必須標注「⚠️ 需驗證」再附上來源
- 不回報無法連結到「創業、管理、人際」的純技術消息
- 不用英文直接回覆，全部繁體中文
