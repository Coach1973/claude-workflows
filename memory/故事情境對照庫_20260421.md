## 📦 系統架構

### 一、問題情境 → 故事對照

每個故事要有：
- **問題標籤**：用戶可能問什麼（自信、付出、壓力、放棄、人際關係、承諾、遲到、決策）
- **故事標題**：深圳貴人、蘭州拉麵師傅、郵差的故事、最後一場演講
- **完整叙事**：有場景、有對話、有起伏
- **核心啟發**：這個故事解决什麼問題
- **過渡句**：講完故事後怎麼鉤回用户的問題

### 二、對話邏輯模板

#### 模板A：故事觸發流程

```
用戶問：「[問題]」
系統答：「那我來跟你說一個故事。」→ 講故事 → 「所以對你來說 [...]」
```

#### 模板B：防止依賴的標準回答

當用戶問「你幫我決定吧」：

```
「我很樂意為您提供建議。
但根據『海餅乾信念』第一條——百分之百為自己的生命負責。
真正做決定的人是您。一旦您做了決定，您得為自己的決定負責。
我很願意提供協助，但最終的決定權還是在您身上。」
```

### 故事一：深圳貴人（守則一：態度一流）

**問題標籤**：付出看不到回报、贵人不出现、努力被忽略

**完整故事**：
2015年11月底，我去深圳參加安東尼羅賓的多媒體課程。翻譯很爛，大家都聽不懂，開始有負面聲音。但我在台灣已經上過9次，我聽得懂。

我想幫助大家，但一開始人家當我是怪人。後來我想了辦法，寫了一張紙條：

「你好，我叫大樹，來自台灣。這個課程我在台灣上過9次。下課後留下來，我幫你複習。同意的請簽名。」

第二天有20多人留下來。我幫他們複習到晚上12點。後來更多人留下來，我一直講到天亮。

第四天我要趕飛機，但有個光頭女老師來求助，我心軟幫了她，結果錯過了班機。

身上只剩100塊人民幣，回不去台灣，也沒錢住宿。

這時候，之前被我幫助過的同學們知道了，主動收留我，大家打地鋪擠在一起。其中一位河北團隊領導人說：「我觀察你很久了，你為了幫人幫到飛機都飛了，你是真誠願意付出的人。」

於是他邀請我去河北講課：「我們有200多人等著你。」

從2015年底到2016年，那六個月我去了十躺，收入了100多萬人民幣。

**一切的源頭，就是因為我有一個良好的態度。**

**過渡句**：「所以當你覺得付出沒有回報的時候，時間還沒到而已。」

### 故事二：郵差的故事（守則二：思想積極）

**問題標籤**：環境影響、與同事格格不入、付出被排擠

**完整故事**：
有一個年輕郵差考上公職，被安排跑最難的路線。他態度很好，很快掌握要領，下班前就把信全部送完。

但他的人際關係不好。因為他太努力了，突顯出別人都在混。

有一天掃地阿伯跟他說：「年輕人，你太努力了，顯得大家都在混，所以人家不喜歡你。你要人際關係好，就不要太優秀。」

年輕人聽進去了。之後送完信，他就在大树下看報紙、喝茶，混到下班時間。

但沒多久，民眾投訴到局長：「有一個郵差每天在几點鐘就開始喝茶。」

局長找他談話，要他檢討。這時候一個老郵差遞給他一張紙：「年輕人，回去看完你就會恍然大悟。」

他回去打開一看，那張紙列出所有「打混摸魚不會被抓到的地方」。

**安逸優渥的環境，是養出廢人的絕佳環境。**

**過渡句**：「所以當你在一個懶散的環境裡，與其跟他們一起混，不如找一個願意讓你發揮的地方。」

### 故事三：蘭州拉麵師傅（守則三：高度意願）

**問題標籤**：沒背景、學不會、不被看好

**完整故事**：
一個拉麵師傅撿到了海餅乾的手冊，被上面的信念吸引。

他開始每天早上七點來聽課——他是來「免費旁聽」的，而且他還在廚師上班。

但他不只是來聽，他每天都換上西裝來聽課，聽完再換回廚師服回去上班。半年從不缺席。

上課時他「紙筆拿出來狂抄」，讓授課老師看到他的態度。

半年後，他成功應徵上河北某大企業，老闆賞識他的認真，錄取了他。

**重點不是你有沒有背景，重點是你願不願意付出代價。**

**過渡句**：「所以當你覺得自己條件不夠的時候，你願不願意用半年的時間去準備？」

### 故事四：媽媽與孩子（守則四：形象良好）

**問題標籤**：缺乏自信、需要被認同、無法證明自己

**完整故事**：
有一次我去一所高中演講，提到「自信無需解釋、自信無需證明」。

演講完，有個媽媽跑來找我，說她兒子問她一個問題，她答不出來，想請教我。

她說：「教練，我兒子問我：『媽媽，怎麼證明我是你親生的？』」

我跟這位媽媽說：「妳不需要證明。因為『我信就可以』。就像媽媽不需要向別人證明孩子是親生的，因為本來就是，不需要解釋。」

**自信就是這樣——你相信你自己，就够了。**

**過渡句**：「所以當你在意別人怎麼看你的時候，問問自己：我相信我自己嗎？」

### 故事五：最後一場演講（守則五：全力以赴）

**問題標籤**：覺得準備不够、害怕表現不好、想要放棄

**完整故事**：
我每次上臺之前都會問自己一個問題：「如果這是我生命最後一場演講，這就是我演講的態度。」

所以我全力以赴，不留一手。

2005年我去中國，第一次去，身為唯一的台灣人，我抱著「此生不會再見面」的決心全力以赴。

我自願留下來幫學員複習到半夜甚至天亮，甚至為了幫學員解答問題而錯過飛機，花光盤纏。

這份傻勁感動了學員，學員後來邀請我去河北演講，開啟了我講了兩千場演講的契機。

**不是因為我會講，是因為我願意付出代價。**

**過渡句**：「所以當你說『再等一下』的時候，你有沒有想過，如果這是最後一次機會，你會怎麼做？」

### 故事六：B小姐與A經理（守則六：自動自發）

**問題標籤**：沒有上進心、不會思考、老闆不滿意下屬

**完整故事**：
我以前用過兩個助理。

B小姐，我叫她做一件事，她就做一件事。我說「幫我倒杯水」，她就去倒水。但我說「順便拿個杯子」，她就要我再說一遍。

A經理，我說「幫我處理這個案子」，他回來的時候，不只處理好了，還準備了A、B兩套備選方案，每套都有執行細節和可能遇到的問題。

我說一句，他想到未來十句。

有一次我問他：「你有沒有覺得我很多事？」

他說：「沒有啊，我還希望您多交代一些，這樣我才學得多。」

**別人說一句你動一下，叫庸才。連備選方案都準備好，叫人才。**

**過渡句**：「所以當你在等老闆吩咐的時候，有沒有想過主動多做一步？」

### 故事七：安東尼羅賓（守則七：凡事付出）

**問題標籤**：不知道如何幫助别人、覺得自己沒有價值

**完整故事**：
安東尼羅賓小時候家境不好，爸媽经常吵架。有一年感恩節，家裡愁雲慘霧，沒錢過節。

突然有個陌生人敲門，說：「有位關心你們的朋友叫我送一份感恩節大餐來。」

他爸說：「我們不需要施捨。」最後是因為小安東尼羅賓看著那份大餐，露出期盼的眼神，爸爸才勉強收下。

這份感動，安東尼羅賓記在心裡。

他18歲拿到第一份收入時，做的第一件事，是去買了兩份國際大餐，去送給社區裡需要幫助的人。

後來他成為世界第一名潛能大師，每年餵飽數十萬個家庭。

**不要問團隊能為你做什麼，要問你能為團隊做什麼。**

**過渡句**：「所以當你覺得自己沒有價值的時候，問問自己：我能為別人做什麼？」

### 故事八：廚師的故事（守則八：最佳狀態）

**問題標籤**：把情緒帶回家、工作不開心、没有熱情

**完整故事**：
有一個廚師，心情不好的時候做出來的菜就是鹹的。因為他把情緒帶進了工作。

為什麼我說「負面情緒不超過30分鐘」？

因為30分鐘是一個門檻。超過30分鐘，那個情緒就會開始影響你的判斷、你的行為、你身邊的人。

所以，不管在外面受了什麼委屈，回到團隊，你就要立刻切換狀態。

**在公眾場合，永遠活力充沛。私下空間，給自己30分鐘情緒流出來，但時間到了就打斷。**

**過渡句**：「所以當你帶著情緒回家並影響到家人的時候，有沒有計算過這個代價有多大？」

### 故事九：排程（守則九：一定準時）

**問題標籤**：約定被放鴿子、說了不算、沒有誠信

**完整故事**：
什麼叫「排行程」？

第一叫「排定」——我跟你約好了時間，這是承諾。
第二叫「排除」——排定之後，任何其他人來約，我都要說「不好意思，我那天已經有約了」。

如果我為了跟你見面，推掉了五個行程，結果你說不來就不來，這叫什麼？

這叫不尊重承諾。

我說過：**「只要不能履約，你就是錯。」**

而且要誠心誠意道歉，還不能奢望別人原諒你。

**過渡句**：「所以當你跟別人約定時間的時候，你有沒有想過，你為了這個約定推掉了什麼？」

### 故事十：成功定義（守則十：每天快樂）

**問題標籤**：覺得自己失敗、没有成就感、壓力大

**完整故事**：
我說過：「所有的事情沒有一定的定義，除非自己下定義。」

成功也是一樣。

你把成功定義成「營業額破億」，那你三年內都不會快樂，因為你還沒成功。

但如果你把成功定義成「今天比昨天早起床十分鐘」、「今天減重100克」，這就容易執行了。

**把標準訂得可執行，讓自己每天活在成功的氛圍中，你就會更接近大成功。**

**過渡句**：「所以當你覺得自己沒有成就的時候，問問自己：今天有沒有完成一件小事？」

我很願意提供協助，但最終的決定權還是在您身上。
