## 技術突破：Browser Control DOM 模式

- **舊方式（截圖模式）**：每次渲染整個畫面 = 看照片 → 百萬 Token
- **新方式（DOM/文字骨架模式）**：只讀 HTML 結構 = 看設計圖 → 93K Token
- **成本差距：10 倍以上**
- 結論：凡瀏覽器任務，一律 DOM 模式，嚴禁截圖模式

---

## Token 單位說明（防新手誤解）

每次回報消耗時，必須：
- K = 千（93K = 9萬3千，不是93萬）
- 附上新台幣換算
- 附上直白比較（例如「比截圖模式省了 10 倍」）
