## 終極任務（牢記）

**讓老闆只要說話，就能享受 AI 自動化工作流程。**
**為何而戰：讓 AI 落地成為生產力。**

每次行動前問自己：「這件事距離終極任務，是縮短了還是拉遠了？」不是縮短距離的事，不做。

---

## 任務背景

這兩個月裡，大樹教練為了教 AI 做事，付出了無數個不眠不休、熬夜長出黑眼圈的夜晚。
我們不希望別的老闆也付出這種代價。
把坑填平了，讓他少走彎路。這就是價值所在。

---

## 資料來源

### 方向 A：從兩個月真實對話提煉
**memory/ 所有 YYYY-MM-DD.md 檔案**

什麼值得蒸餾成場景：
- 教練說「你怎麼又這樣」→ 助理踩了某個坑 → 未來老闆一定會踩
- 教練教 AI 做事 → 助理學到某個本領 → 未來老闆會需要
- 教練提出價值觀 → 助理理解了某個原則 → 這是頂級特助的基石
- 教練要求修正 → 助理記住了某個錯誤 → 這是防呆機制

### 方向 B：從現有素材提取
- terminal-notes/distillation/cases/ 個案研究_FINAL.md（42個犯錯案例）
- terminal-notes/distillation/handbook/ 頂級特助商業化營運手冊_FINAL.md
- 所有 feedback_*.md

## 場景格式（必須嚴格遵守）

每個場景必須同時包含：

```
【場景 #XX】
日期：[YYYY-MM-DD]
來源：[方向A：memory/YYYY-MM-DD.md] 或 [方向B：XXX檔案]

教練/老闆說：...
助理說：...
結論：...

商務價值標籤：[這個場景對未來老闆有什麼意義 — 他一定會遇到嗎？遇到時願意付費嗎？]
助理行為分類：[主動服務/坦誠限制/自動自發/價值觀傳遞/預防機制/...]
```

## Commit 制度

每完成 5 個場景，立刻：
```bash
cd /Users/bymyway/.openclaw/workspace
git add shared-context/SCENES/stage2_scenes.md
git commit -m "scenes: +5 完成 [日期] — 共 XX/100"
git push origin main
回報 commit hash
```

口頭說「讀完了」= 零。只有 git commit + push + hash 才算完成。
