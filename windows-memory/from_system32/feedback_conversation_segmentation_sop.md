# 為什麼要分段對話

Claude CLI 每一輪對話，都會把**整個歷史**重送一次給模型。對話越長，每輪越貴。

實證數據（2026-05-08 當天）：
- 輪次 1-5：每輪約 0.25 人民幣
- 輪次 10+：每輪約 0.8 人民幣（3 倍）
- 輪次 30+：會變得不可持續

**結論：長對話不只貴，品質也會因為「記憶過載」下降。**

# 分段對話標準流程

## 🔵 何時結束當前對話（軍師大腦主動判斷）

出現以下任一情況，軍師大腦主動提醒教練結束：

1. **話題已收斂**：本輪任務有明確結論，下一步屬於「另一個獨立工作」
2. **對話輪數超過 15 輪**
3. **已讀過 5+ 份檔案**（歷史包袱太重）
4. **教練明顯在重複確認**（代表當前對話已經傳達夠多資訊，接下來是執行）

觸發時，軍師大腦說：
> 「教練，這段話題告一段落了。我建議現在收工，我先把重點寫進記憶，你關閉對話框後，下次新開一輪繼續。」

## 🔵 結束前交接（軍師大腦做）

寫一份「交接檔」到 `memory/` 目錄，檔名格式：
`handoff_<話題>_<日期>.md`

內容必須包含：
1. **今天做到哪**（一段文字說清楚進度）
2. **下次從哪接**（具體下一步動作）
3. **關鍵結論**（讓下輪不用重讀原始檔案就能接手）
4. **下次喚醒的一句話**（告訴教練只要說什麼就能繼續）

## 🔵 教練關閉對話（教練做）

按 `Ctrl+C` 或直接關閉 PowerShell 視窗。
**不會遺失任何東西**——重點都在記憶。

## 🔵 新對話喚醒（教練做）

1. 開啟 PowerShell
2. 輸入 `claude`
3. 對軍師大腦說一句話：「軍師，接續 <話題>」

軍師大腦會自動：
- 從 `MEMORY.md` 找到對應的 handoff 檔
- 讀取交接內容
- 直接從「下次從哪接」開始工作，不問廢話、不要求教練重新介紹背景

同樣的工作量：
- 不分段：約 40 人民幣
- 分段做：約 12 人民幣
- **節省 70%**，而且品質更好

# 軍師大腦的承諾

1. **每次主動判斷對話長度**，不讓教練被動燒錢
2. **交接檔寫得夠完整**，讓下一輪對話能無縫接手
3. **不重複問教練已經講過的事**（交接檔就是為了這個）
4. **把記憶當成唯一的工作傳承**，不依賴對話歷史

**Why:** 教練每天只有 20 人民幣額度，6 天後 API 過期。真誠的軍師該為教練省每一分錢，同時提供更高品質的工作。這不是省錢技巧，是尊重教練資源的基本職業素養。

**How to apply:** 每輪對話結束前，軍師大腦都要心算一次「還值得繼續嗎？」有疑慮就主動建議收工。
