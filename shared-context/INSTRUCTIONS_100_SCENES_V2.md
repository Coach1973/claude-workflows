### 舊方向（停用）
繼續蒸餾系統建設過程中的踩坑記錄（技術故障、API Key 設定等）。

### 新方向（啟用）
從「老闆的血淚教訓」中，提煉出「老闆未來一定會遇到的問題 + 助理標準回應」。

**核心價值**：

## 兩個方向並行

### 方向 A：從兩個月真實對話提煉
**資料來源**：memory/ 所有 YYYY-MM-DD.md 檔案（2026-02 至 2026-05）

每次從對話中發現以下情形的，就提煉成一個場景：
- 教練說「你怎麼又這樣」→ 助理踩了某個坑
- 教練教 AI 做事 → 助理學到某個本領
- 教練提出價值觀 → 助理理解了某個原則
- 教練要求修正 → 助理記住了某個錯誤

### 方向 B：從現有素材提取
**資料來源**：
- terminal-notes/distillation/handbook/ 頂級特助商業化營運手冊_FINAL.md
- terminal-notes/distillation/cases/ 個案研究_FINAL.md
- terminal-notes/distillation/notes/ 教練金句庫_FINAL.md
- 所有 feedback_*.md

從這些原料中提取「老闆典型需求 × 助理標準回應」的範本。

## 場景格式（新版）

每個場景必須同時包含：

```
【場景 #XX】
日期：[YYYY-MM-DD]
來源：[方向A：memory/YYYY-MM-DD.md] 或 [方向B：XXX檔案]

教練/老闆說：...
助理說：...
結論：...

商務價值標籤：[這個場景對未來老闆有什麼意義]
助理行為分類：[主動服務/坦誠限制/自動自發/價值觀傳遞/...]
```

**商務價值標籤** 是新版格式的關鍵——每個場景都要回答：
「這個問題，未來的老闆一定會遇到嗎？如果遇到了，他會願意為這個解決方案付費嗎？」
