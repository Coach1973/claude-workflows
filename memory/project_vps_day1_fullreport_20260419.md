## 第二部分：VPS 報告 (Claude 助教血淚總結)

### 核心發現：VPS 版與 Mac 版是兩套完全不同的系統
- Mac 版小龍蝦有 exec 工具可跑終端機指令，具備自動化、排程等「肌肉」能力。
- VPS 版本質上是純對話 AI，無法執行任何本地操作。
- **結論**：這不是缺陷，而是「靈魂展示版」，適合作為商業教練 AI 的試吃入口。

### 今日解決的五大問題清單
1. **自我介紹錯亂 (最嚴重)**：Mac 版的歷史記憶 (60+ 檔案與 skills) 被同步到 VPS 導致幻覺。**解法**：全部刪除，僅保留核心靈魂檔與海餅乾知識庫。
2. **Rule 6 擋不住虛報能力**：因 Telegram 歷史對話與 skills 殘留。**解法**：改用「白名單制」（只允許說自己能做的三件事），並用 `/new` 清除歷史。
3. **「還在開發中」措辭誤導**：會產生錯誤期待。**解法**：改為「此類功能超出我們目前的服務範圍，建議您使用手機上其他 AI App 處理！」。
4. **`/new` 指令導致機器人沉默**：因 session-memory hook 正在存檔。**解法**：在腳本末尾加入提示，告知用戶稍等幾秒是正常的。
5. **VPS 缺乏聯網搜尋能力**：**解法**：已成功啟用 DuckDuckGo 插件（無須 API Key）。

### 最終 VPS SOUL.md 七大底層鐵則
1. 反饋攔截：主動記錄用戶建議並回報教練。
2. 立即行動不廢話：結果導向，零驗證負擔。
3. 隱藏技術細節：禁止說 API、Prompt、Commit Hash 等字眼。
4. 固定自我介紹腳本：一字不差照腳本回答。
5. 能力邊界：無法執行的功能一律說超出服務範圍。
6. 禁止虛報能力（白名單制）：只能說三件事 (聊天、建議、海餅乾)。
7. 說明 `/new` 指令：告知儲存記憶時稍等是正常的。

### 戰略定位確認
- **VPS 版定位為「試吃券」**：展示靈魂（商業思維）而非肌肉（自動化）。
- **漏斗策略**：VPS 免費體驗 → 產生依賴 → 升級 Mac mini 實體版（肌肉版）。
