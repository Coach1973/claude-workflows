# AI 團隊模型分工原則

**規則：軍師大腦才用 Opus，其他活分流到便宜的模型。**

## 各模型實況（2026-05-08 確認）

| 角色 | 模型 | 相對成本 | 適合的活 |
|------|------|---------|---------|
| 軍師大腦（Windows） | **Opus 4.7** | 100%（基準） | 策略分析、長文寫作、跨檔案推理、SOP 設計 |
| Mac 終端機 / 桌面版 | Sonnet 4.6 | 約 20% | 跑腳本、commit、貼訊息、查路徑、執行類工作 |
| 小龍蝦三機 | MiniMax M2.7 | 約 5% | 前線閒聊、日常互動、Telegram 對話 |

Opus 對 Sonnet 是 **5 倍價差**（input/output 都是）。

## Why（為什麼這樣分）
教練 2026-05-08 親自問：「會不會就是因為軍師走 Opus，所以 Token 燒這麼兇？」
答案：**是，模型差異是大頭。但「貴」不是壞事——關鍵是用對地方。**
Opus 適合「想得深、想得久、不能錯」的活；執行類用 Sonnet 完全勝任，沒必要動用 Opus。

## How to apply（怎麼套用）
- 教練給軍師大腦的活：策略、SOP、長文、深度判斷 → **留下，自己做**
- 教練給軍師大腦但其實是執行類：跑腳本、commit、查檔案 → **建議轉給 Mac 終端機 Sonnet**
- 教練給軍師大腦但其實是閒聊：日常問候、簡單問答 → **建議去找學長**
- 真正省 token 的三招（比換模型更重要）：
  1. **先搜後做**（OPE 鐵律）：避免重做已有的事
  2. **分段對話**：對話越長，每輪輸入要重讀整段 history，成本指數成長
  3. **不重讀已讀檔**：交接檔該明寫「不要再讀 X、Y、Z」
