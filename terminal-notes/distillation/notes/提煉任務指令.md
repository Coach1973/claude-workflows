## 你該做什麼

**蒸餾目標**：把散落在系統各處的對話精華，全部集中到 `terminal-notes/distillation/` 備用。

**隔離原則**（絕對遵守）：
- 只讀不寫到 `terminal-notes/distillation/` 以外的任何檔案
- 不觸發 Bot 指令，不改 `.openclaw` 設定
- commit 只在 `terminal-notes/` 範圍內

## 第二優先：Claude 桌面版對話

### 資料在哪裡

路徑：`~/Library/Application Support/Claude/claude-code-sessions/`
- 每個資料夾 = 一個 workspace session
- JSON 檔案包含：sessionId、model、title、createdAt、lastActivityAt
- **實際對話內容**存在 `claude-code-sessions/<uuid>/local_*.json`

### 蒸餾方法
1. 列出所有 session：`ls ~/Library/Application Support/Claude/claude-code-sessions/`
2. 讀取 session title 和時間，找有價值的
3. 對話內容在 local_*.json 的 `messages` 或 `transcript` 欄位（可能需用 Claude Code CLI 讀取）

### 特別注意
Claude Code CLI 目前有 auth bug，修復方式：在 `~/.claude/settings.json` 的 `env` 區塊加入：
```json
"ANTHROPIC_AUTH_TOKEN": "你的MiniMax Key"
```

## 蒸餾輸出格式

每個被提煉的檔案，完成後寫入對應資料夾：

```
terminal-notes/distillation/
├── handbook/              ← 核心守則全集（已完成）
├── cases/                 ← 個案維修記錄（已完成）
├── reference/             ← 檔案索引（已完成）
└── notes/
    ├── 2026-05-04_Telegram蒸餾.md
    ├── 2026-05-04_Claude桌面對話蒸餾.md
    ├── 2026-05-04_未讀檔案蒸餾.md
    └── 教練金句_海餅乾精華.md
```

```markdown

（這段內容如何加強我們的商業模式）
```

## 執行流程（每 15 分鐘輪一次）

```
① 檢查 memory/ 最新日期（今天/昨天）
② 讀取 BOT_MESSAGES.md 最新 200 行
③ 讀取 daily_YYYY-MM-DD.md
④ 蒸餾寫入 distillation/notes/
⑤ git add + commit + push + 回報 hash
⑥ 選一個還沒讀的核心檔案讀並蒸餾
⑦ /loop 15m 重複
```

## 給教練的提醒

如果終端機又說「無新增」，代表它只查了 git diff，沒去讀 actual 檔案。請用以下指令：

```
去讀 memory/2026-05-04.md 和 memory/2026-05-03.md，把所有跟「頂級特助系統商業化」相關的內容提煉出來，寫入 terminal-notes/distillation/notes/。只蒸餾，不修改其他任何檔案。完成後 commit hash 給我。
```

---

## Commit Hash 制度

口頭說「讀完了」= 零。
只有：`git add + git commit + git push + 回報遠端 hash` 才算完成。
每次蒸餾完，必須馬上 commit，不能累積。
