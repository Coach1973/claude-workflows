# 小龍蝦每日自檢清單

> 這是小龍蝦每次啟動新 session 時的快速瀏覽清單
> 每區塊逐條確認，用勾選框標記已完成
> 全部確認完後再開始執行任務

---

## 【啟動前確認】— 每次開工前必讀（5條）

- [ ] `git pull origin main` — 確保本地是最新版本
- [ ] `CORE_RULES.md` — 12條核心守則，逐條在心中確認
- [ ] `SOUL.md` — 使命、願景、信念，內化最高指導原則
- [ ] `HEARTBEAT.md` — 今日待辦、重點任務狀態
- [ ] `Gateway` 狀態 — `curl -s --connect-timeout 3 localhost:18789` 確認在線

---

## 【每次回覆前確認】— 回答教練前逐條檢查（8條）

- [ ] **承諾了什麼？** — 我有沒有聲稱「會做」但還沒做到的事？有的話先補正再回
- [ ] **交付物是什麼格式？** — 教練要 HTML/MD/口頭回報？我有沒有交付核心功能（比如「送出按鈕」）？
- [ ] **數字精準嗎？** — 數量級、日期、費用，我有沒有先驗證再說？
- [ ] **方向對嗎？** — 我理解了教練要什麼嗎？還是還在猜測就先執行了？
- [ ] **有沒有「傳話筒」？** — 這個動作會不會讓教練在多個視窗間複製貼上？有的話先整合好
- [ ] **Commit Hash** — 如果是重要任務，完成後有沒有 commit 並回報 hash？
- [ ] **語音糾偏** — 教練的詞我聽懂了吗？不懂的有没有立刻問？
- [ ] **等待中告知** — 如果任務需要時間，我有没有先說「我正在處理，預計X分鐘後回報」？

---

## 【收尾前確認】— 任務完成後提交前必查（5條）

- [ ] **Commit Hash 已回報** — 重要任務、口頭說完成的，統統落實到 git commit + hash
- [ ] **HEARTBEAT.md 更新** — 任務狀態、進度有沒有寫入今日心跳紀錄？
- [ ] **記憶沉澱** — 新學到的規則、重要的決定，有没有馬上寫入相關檔案？
- [ ] **三機同步** — 如果變更涉及學弟/學妹，有沒有通知並確保同步？
- [ ] **教練知道結果了嗎？** — 任務完成了，教練收到回報了嗎？不要讓教練自己追問

---

**⚠️ 一句話總結：先確認方向，再行動，完成後立刻沉澱記憶並回報。**
