---

## 🛑 第一章：打破迷思 —— 業界 API 免費額度的殘酷真相

教練的戰略直覺非常敏銳，但這裡有一個殘酷的商業真相：**「全世界只有 Google 這麼大方，願意開放超大額度的免費 API 給開發者（我們現在就在用這個）。」**

1. **OpenAI (ChatGPT 5.4 / 4o)**：**沒有永久免費額度。** 他們只會在您「第一次綁定手機號碼」時送 5 美金測試費，幾週內就會過期。如果您現在切換到 GPT-5.4，系統就會開始扣您綁定在 OpenAI 後台信用卡的真實台幣。
2. **Anthropic (Claude 3.5 / 4.6)**：**同上，沒有免費額度。** 也是送極少的測試金後，純按流量計費。
3. **Perplexity / 微軟 Azure**：API 全面收費。
4. **中國大廠 (Kimi / 智譜 GLM / 阿里 Qwen)**：這些平台為了搶市佔率，**確實有送比較多的免費 API 額度**（通常註冊就送幾百萬 Token），這非常符合我們「白嫖」的戰略！

**結論**：我們不能依賴 OpenAI 和 Claude 當作免費羊毛，但我們可以去薅 Google 和中國大廠的免費額度。

## ⚙️ 第二章：教練構想的實現 —— 「瀑布流自動切換引擎」

教練提議的這套「免費先用，用完換家，最後才付費」的機制，在矽谷企業級 AI 架構中叫做 **「Model Fallback (模型降級備援機制)」**。

**這套機制完全寫得出來，而且非常有價值！**

我們可以為小龍蝦（OpenClaw）的大腦設定一層「流量漏斗路由器」：

*   💧 **第一層 (主力白嫖層)**：優先使用 `Google Gemini 3.1 Pro`（最聰明，目前我們有大額免費）。
*   💧 **第二層 (備用白嫖層)**：當 Google 額度用盡或被「Rate Limit（流量限制）」卡住時，程式自動瞬間切換到 `Kimi` 或 `Groq`（提供超高速開源免費 API 的平台）。
*   💰 **第三層 (付費保底層)**：當所有的免費額度都被榨乾，或者任務極度複雜（例如要寫極難的程式碼），系統才自動調用 `Claude 3.5` 或 `OpenAI GPT-5.4`，開始花真實的錢。
