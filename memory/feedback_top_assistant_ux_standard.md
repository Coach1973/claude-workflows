## 教練原話（2026-04-12）

> 「我想試試整個順序流不流暢，因為沒試之前都是理想，試過之後才知道行不行。
> 我們頂級特助系統，是不能讓客戶去感受到我現在這麼多的無奈。」

## 今天踩到的坑（不能讓客戶踩）

1. groupPolicy 設成不存在的值 `"all"`，沒有任何報錯，靜默失效
2. Telegram 隱私模式預設開啟，bot 加進群組後完全無反應
3. 修法需要客戶自己去 BotFather 操作 `/setprivacy`
4. 改完設定還要手動移除 bot 再重新加入群組才生效
5. 整個過程來回 5-6 次，燒掉大量額度，客戶完全不知道哪一步有問題

## 黃金標準

**客戶只能有一個動作：說話。**

所有技術設定必須在**部署時就預先完成**，不能靠客戶在使用過程中補做。

## 頂級特助部署前必做清單（群組功能）

- [ ] BotFather 關閉隱私模式（`/setprivacy` → Disable）**在交付前完成**
- [ ] 測試 bot 能收到群組普通訊息（不需要 @ 或 /）
- [ ] groupPolicy 設為 `"open"`（不是 "all"）並驗證有效
- [ ] bot 加進群組後發一條測試訊息確認有回應
- [ ] 以上全部通過才交付給客戶

## 設計哲學

教練是原型機的第一個用戶。他踩過的每一個坑，都是未來客戶的保護墊。
凡是讓教練說「我被耍著玩」的流程，就是必須在系統層解決的問題，不是讓客戶學會接受的問題。

**「沒試之前都是理想，試過之後才知道行不行」** — 這是頂級特助的品質標準。
